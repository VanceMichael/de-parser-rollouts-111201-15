# 本地运行说明

先运行单元测试，再执行演示命令。演示从干净临时目录发起真实请求并处理响应，不需要外部站点。

```bash
python3 -m unittest discover -s tests -v
python3 -m collector rollout-demo
```

## 重放与发布运维要点

- 重放启动即冻结：响应 seq 上界、规则代码摘要、字段契约、运行参数进入同一 bundle 摘要；
  冻结点之后归档的响应不会被重放读取，重放任务引用冻结点之外的 seq 会被拒绝。
- 重放逐项提交（pending/done/quarantined），中断后重开数据库调用 `run_all` 即可续跑，
  已完成项自动跳过；任务被取消或标记失败后不可续跑、不可发布。
- 发布不需要停采：切换事务持写锁期间，正常采集在锁上排队；事务提交前重新捕获水位，
  排队期间到达的响应进入同事务追赶。若追赶中出现不兼容页面，页面进 catchup 隔离区，
  不阻断其余切换。
- 回退只翻转可见版本指针，不删除任何版本行、隔离记录或事件；回退后可重新发布同一影子版本。
- 规则代码摘要在每次打开数据库时复核，摘要不符说明规则在发布后被改动，数据库拒绝打开；
  需要改规则时应登记新的规则版本，而不是修改已发布版本。
- 常规导入失败时返回非零退出码，事务中的原文和记录会一起回滚，可保留源文件再次处理。
- 查询模式只读取当前数据库，不会补采或删除来源数据。需要长期保留证据时，请备份整个数据库。
- 本地响应服务支持状态码、响应头、文本或 base64 字节正文；未配置路径返回未找到。
- 每条路径的脚本独立推进，最后一个响应会重复；可借请求记录核对调用顺序。
- 数据文件的路径均相对项目根目录，修改工作目录前请确认输入和数据库参数。
